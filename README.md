# tolstunov.pro

Personal site of Nikita Tolstunov, Head of Technology at Stillman Digital (Tolstunov IT).

Static HTML/CSS/JS, deployed with GitHub Pages using the custom domain in `CNAME`.

## Structure

- `index.html`: page content (hero, about, expertise, experience, contact)
- `assets/css/style.css`: styles; colors and fonts are defined as variables in `:root`
- `assets/js/main.js`: sticky nav state and scroll-reveal animations

## Local preview

Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.
